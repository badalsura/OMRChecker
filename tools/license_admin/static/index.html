Load your private key

Point to your existing private_key.pem. It is read into memory for this session only and never written anywhere.

Generate a new key pair

Only the first time, or when rotating keys. The public key is copied into the app at src/licensing/public_key.pem so builds can verify licenses. Keep the private key secret and backed up.

Issue a license

Paste the customer's activation request (from the app's Activate screen) to bind the license to their machine, or enter a fingerprint directly.
