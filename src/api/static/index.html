      New bulk job

      Upload files ⓘ
      Copies the sheets from this computer to the server. Use it when the server is another machine, or for a few hundred sheets.
      …or a folder on the server ⓘ
      Reads the sheets where they already are; nothing is copied. Fastest for large batches. The folder must be on the machine running OMR Checker (on the portable app, that is this PC) or on a network drive it can reach.
      Examples: Windows D:\scans\batch-01 · network share \\server\scans\batch-01 · Linux /srv/scans/batch-01

      Auto-generate from samples

      Upload ~20 filled sample sheets and, optionally, a labels file: CSV or Excel (.xlsx) with a file-name column (“File Name”, “file”, … any spelling) plus one column per field. An answer-string column such as ANS (“CB A*D…”: space = blank, * = several marks) is split into q1, q2, … The draft opens in the editor with the items that need verification highlighted.
